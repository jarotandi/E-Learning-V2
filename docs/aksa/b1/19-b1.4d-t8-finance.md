# B1.4D-T8 — Financial Center Extraction

## Authority
- docs/aksa/b1/10-b1.4d-execution-map.md

## Summary

B1.4D-T8 extracts the Financial Center (`/admin/commerce/finance`) from the `AdminDashboard` monolith into a dedicated Finance domain under `src/features/admin/commerce/finance/`.

## Extraction Boundary

**Finance owns exactly 5 storage keys:**
- `theprams_demo_transactions`
- `theprams_demo_payment_proofs`
- `theprams_demo_finance_entries`
- `theprams_demo_finance_realizations`
- `theprams_demo_assets`

**Finance owns ZERO audit/notification keys:**
- `theprams_demo_audit_events` (owned by AdminDashboard)
- `theprams_demo_notifications` (owned by AdminDashboard)

**Shared infrastructure stays in AdminDashboard:**
- `auditEvents`, `notificationEvents`, `recordAudit`, `queueNotification`, `notify`, `downloadTextFile`

**Cross-domain dependencies (injected, never imported):**
- `users` / `persistUsers` (from Users domain) for student auto-create
- `notify` / `recordAudit` / `queueNotification` / `downloadTextFile` (shared adapters)

## T8/T9 Boundary

**Stays in AdminDashboard (NOT extracted in T8):**
- `adminTeam` (T9)
- Deep Analytics / Reports (T9)
- Settings (T9)

**Extracted in T8:**
- All Finance state, handlers, derived data, and UI components

## Architecture

```
AdminDashboard
  ├─ useAdminFinanceDomain({ users, persistUsers, notify, recordAudit, queueNotification, downloadTextFile })
  │    → financeDomain (5 storage keys, all Finance state/handlers/derived data)
  └─ <AdminFinancePage domain={financeDomain} auditEvents={auditEvents} notificationEvents={notificationEvents} />
       ├─ Payments subview
       ├─ Inputs subview
       ├─ Realization subview
       ├─ Assets subview
       ├─ Accounting subview
       ├─ Reports subview
       └─ Audit subview
```
