## 5. Marketing — state ownership + in-memory semantics

`useAdminMarketingDomain({ notify, recordAudit })` is invoked **exactly once** by the persistent `AdminDashboard`. The hook owns `campaignForm` and `isCampaignEditorOpen`; the page/dialog never invoke it.

- **Canonical campaign form state (single authority, in-memory):** `useState(defaultCampaignForm)` — no localStorage, no storage key.
- **Campaign editor modal open state:** `isCampaignEditorOpen` — survives client-side tab changes.
- **Currency helpers (exact legacy semantic):**
  - `currencyOptions`: exact 4 entries (IDR, USD, SGD, MYR) with symbol + locale.
  - `parseCurrencyAmount`: `Number(String(value).replace(/[^\d]/g, '')) || 0`.
  - `formatCurrencyAmount`: lookup currency (fallback to first), amount = number OR parse, return `${symbol} ${amount.toLocaleString(locale)}`.
- **Derived budget metrics (exact legacy formula):**
  - `campaignTotalBudget = parseCurrencyAmount(campaignForm.totalBudget)`
  - `campaignDailyBudget = parseCurrencyAmount(campaignForm.dailyBudget)`
  - `campaignEstimatedDays = daily > 0 ? Math.max(1, Math.floor(total / daily)) : 0`
- **Zero persistence:** Marketing owns **ZERO** storage keys. Campaign draft is React in-memory only. Total admin storage keys remain **13/13**.

## 7. Campaign Editor — open/save parity

- **openCampaignEditor()** opens the modal. **Does NOT reset** `campaignForm` — preserving the legacy behaviour where a draft survives closing/tab-switching.
- **closeCampaignEditor()** closes the modal (header X and Batal button).
- **saveCampaignDraft()** does **exactly**:
  ```ts
  recordAudit('Digital Marketing', 'Create Campaign Draft',
    `${campaignForm.name} - ${formatCurrencyAmount(campaignTotalBudget, campaignForm.currency)}`);
  closeCampaignEditor();
  notify('Campaign baru tersimpan sebagai draft dengan budget fleksibel.');
  ```
  - **No** localStorage write.
  - **No** campaign array.
  - **No** backend persistence.
  - **No** form reset (draft stays in `campaignForm`).
  - **No** validation beyond what legacy had.
