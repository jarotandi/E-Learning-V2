## What Changed

### 1. Feature Decomposition: `src/features/learn/dashboard/`

| File | Responsibility |
|------|----------------|
| `legacyLearnerAccess.ts` | Extracted account/entitlement logic (single source of truth for dashboard + LearnerLayout profile disclosure) |
| `LearnerDashboardPage.tsx` | Main dashboard page — composes all feature components, CONTENT ONLY |
| `DashboardWelcome.tsx` | Greeting + account status card (replaces header account card) |
| `DashboardStats.tsx` | Four metric cards: Progress, Last Score, Ranking, Completed Tryouts |
| `ScoreTrendCard.tsx` | Area chart with AKSA token colours (tealAccessible/mint gradient) |
| `ContinueLearningCard.tsx` | "Lanjutkan Belajar" with progress bar → `/app/learn` |
| `FeedbackCard.tsx` | Recent feedback + actions (view all, write testimoni) |
| `TodayScheduleCard.tsx` | Live sessions list (premium-gated) + "Lihat Semua Jadwal" |
| `LearningRecommendationsCard.tsx` | Weak-subject recommendations from tryout results |
| `index.ts` | Public barrel export |

**Design-system usage:** Card, Button, ButtonLink, Badge, IconButton — no legacy `card-premium`, `btn-primary`, `text-brand-blue` in new code.

### 2. StudentDashboard → Thin Compatibility Wrapper

**Before (23.6 KB):** Full app shell with:
- 256px navy sidebar (`bg-brand-navy`) with TP monogram
- "The Prams" / "Edu Platform" branding
- 7 sidebar nav items (Overview, Kelas Saya, Tryout, Hasil & Ranking, Jadwal, Profil, Keluar)
- Sidebar account panel with premium status bar
- Standalone header with duplicate account card + notification bell
- Hard-coded chart colours (`#2563eb`, `#f1f5f9`, `#64748b`)
- `text-brand-blue` (#009688) on white — 3.67:1 contrast violation

**After (<1 KB):** Thin wrapper that delegates to `LearnerDashboardPage`
- Preserves LegacyRouteBridge prop surface: `setView`, `user`, `logout`, `onUpgrade`
- `logout` prop accepted but unused (LearnerLayout owns logout now)
- No sidebar, no header, no app shell — pure content

### 3. LearnerLayout Profile Disclosure (Logout Relocation)

**New accessible account menu in header:**
- Trigger: avatar button with `aria-expanded`, `aria-controls`, `aria-label="Menu akun {name}"`
- Menu (role="menu"): Profil → `/app/profile`, Keluar → `requestLogout()`
- Escape closes menu, focus returns to trigger
- Outside click closes menu
- Uses `LogOut` icon from lucide-react

### 4. Shell Integration

**AppRouter changes:**
- `/app` (dashboard) moved from bare `BareLegacyRoute` into `LearnerLayout`
- `/app/learn` remains bare (LearningPage self-chrome) — B1.4C will decompose
- No URL change — canonical learner home stays `/app`

**legacyViewRoutes.ts updates:**
- `SELF_CHROME_LEGACY_VIEWS`: `['dashboard', 'learning']` → `['learning']`
- `dashboard` removed from self-chrome registry
- `NAVBAR_HIDDEN_LEGACY_VIEWS` unchanged (dashboard stays navbar-hidden — PublicHeader and LearnerLayout are different surfaces)

**verify-routes.mjs updates:**
- `SELF_CHROME` constant: `['dashboard', 'learning']` → `['learning']`
- All 174 checks pass

### 5. Legacy Capability Mapping (All Preserved)

| Legacy Sidebar Item | New Access Path |
|---------------------|-----------------|
| Overview | `/app` (dashboard home) |
| Kelas Saya | `/app/learn` (LearningPage — still self-chrome) |
| Tryout | `/app/assessment` (Assessment Center in LearnerLayout sidebar) |
| Hasil & Ranking | Via Assessment Center → result flow (`setView('result')`) |
| Jadwal | `/app/calendar` (Calendar in LearnerLayout sidebar) |
| Profil | `/app/profile` (Profile in LearnerLayout sidebar + header disclosure) |
| Keluar | LearnerLayout header profile disclosure → `requestLogout()` |

### 6. Entitlement / Premium UI Gating (Preserved)

- Uses extracted `useLegacyLearnerAccess()` — single source of truth
- `theprams_demo_users` localStorage key unchanged
- Free / Paid / Scholarship Review / Paid Pending states identical
- Assessment Center & Calendar sidebar items: visually disabled for non-premium (opacity-40, Lock icon, no navigation)
- **No real authorization** — B2 owns enforcement. UI gating only.

### 7. Accessibility & Contrast Corrections

- Chart colours migrated to AKSA tokens: stroke `tealAccessible` (#00796b), gradient `tealAccessible`/`mint`
- Dashboard metric cards: icon colours use design-system tokens (teal, amber, emerald, indigo)
- No `text-brand-blue` in new dashboard code
- Heading hierarchy: h1 (welcome), h3 (section titles)
- Interactive elements: real `<button>`/`<a>` with focus-visible
- Minimum 44×44 touch targets on all controls
- Profile disclosure: Escape, outside-click, focus-return
