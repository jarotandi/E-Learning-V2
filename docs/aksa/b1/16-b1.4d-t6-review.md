No `AdminReviewWorkspacePage`, no combined Review store, no new route.

## 5. Inquiries — state ownership + storage

`useAdminInquiriesDomain({ notify, recordAudit, queueNotification })` is invoked **exactly once** by the persistent `AdminDashboard`. The hook owns `websiteQuestions`; the page never invokes it.

- **Canonical key (exact, unchanged):** `theprams_demo_website_questions`, declared once as `INQUIRIES_STORAGE_KEY` inside the Inquiries domain.
- **Initial read:** `useState<WebsiteQuestion[]>(() => readStorageArray(INQUIRIES_STORAGE_KEY))` — the legacy read quirk is preserved (an absent key yields `[]`).
- **Write:** `localStorage.setItem(INQUIRIES_STORAGE_KEY, JSON.stringify(nextQuestions))`.
- **No rename, no migration, no second key.** The key legitimately moved **from the monolith into Review/Inquiries** — the only key the Review domain owns.
- **Adapter injection (no cycle):** `notify`, `recordAudit`, `queueNotification`. The hook re-declares the monolith's private `NotificationEvent` channel union (`'Email' | 'WhatsApp' | 'System'`) so it can accept the injected adapter **without importing `AdminDashboard`**. It owns no audit/notification infrastructure.

`AdminDashboard` no longer declares `websiteQuestions`, and no longer implements `saveWebsiteQuestions` / `saveWebsiteQuestionAnswer` / `openQuestionWhatsapp`.

## 7. Testimonials — in-memory semantics + filter contract

`useAdminTestimonialsDomain({ notify })` is invoked **exactly once** by the persistent `AdminDashboard`.

- **Seed preserved:** `useState<Testimonial[]>(TESTIMONIALS)` — seeded **exactly** from the legacy `TESTIMONIALS` constant.
- **Initial filter:** `'All'`.
- **Filter contract (exact):** `'All' | 'Pending' | 'Approved'`. The UI still exposes **no Rejected tab** — none was added.
- **Derived (preserved even where unused):** `pendingTestimonials`, `approvedTestimonials`, `rejectedTestimonials`.
- **`visibleTestimonials`:** `'All'` → every testimonial; otherwise `status === testimonialFilter`.
- **Status update:** `setTestimonials(prev => prev.map(t => t.id === id ? { ...t, status } : t))` + `notify(\`Testimoni ditandai ${status}.\`)` for `'Approved' | 'Rejected'`.
- **Delete:** the legacy inline mutation extracted to `deleteTestimonial(id)` — `prev.filter(item => item.id !== id)` + `notify('Testimoni dihapus.')`. **No confirmation invented, no persistence added, no audit.**
- **In-memory only:** the Testimonials domain adds **no** `localStorage` usage and **no** `theprams_demo_*` key.
- **Motion preserved:** the card remains `<motion.div layout ...>`; the extraction is not a redesign.
