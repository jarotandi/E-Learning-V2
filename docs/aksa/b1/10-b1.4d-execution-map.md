## State-Preservation Architecture (Accepted)

T1 establishes a **single persistent route branch** for admin:

```text
<Route element={<AdminLayout />}>
  <Route path="/admin/*" element={<AdminRouteBoundary />} />
</Route>
```

- Admin child navigation does **NOT** use 13 independent `<Route>` elements. All canonical admin URLs share one mounted boundary.
- For canonical tab URLs, `pathToLegacyView(path)` returns `'admin'`, so `currentView` remains `'admin'`.
- `LegacyRouteBridge` keeps `key={currentView}` (not `location.pathname`). `AdminDashboard`, `LegacyRouteBridge`, `AdminRouteBoundary` are **not** keyed by pathname.
- `AdminShellContext` (mounted in `AdminLayout`) derives `activeTab` from `adminPathToTab(location.pathname)`; `AdminDashboard` consumes it and keeps a thin `navigateToTab` shim (`setActiveTab`) to preserve all existing call sites. (Before T2 the derivation lived in `AdminDashboard`.)
- **SOURCE CONTRACT only.** Runtime transient-state persistence (form drafts, editing records, selected rows, open modals, finance subview, filters, upload progress) is **NOT VERIFIED IN BROWSER** by T1. T2 adds a partial browser smoke (search draft survives tab switches) — see the T2 gates section and `docs/aksa/b1/11-b1.4d-t2-admin-shell.md`.

## Anti-Monolith Rule

**B1.4D MUST NOT** become:

```
AdminDashboard.tsx 402 KB → AdminWorkspacePage.tsx ~400 KB
```

Target architecture:

- `AdminDashboard.tsx` → eventually a **thin compatibility wrapper** (preserves exact legacy prop contract).
- `AdminWorkspacePage.tsx` → a **small composition/orchestration surface only**.
- Domain behavior/state moves incrementally into coherent **domain components**, **domain hooks**, **pure models**, and **shared utilities**.
- Only state genuinely shared across domains is lifted upward.

The pure routing contract (`src/features/admin/shell/adminWorkspaceModel.ts`) is intentionally small and pure (no React/router/localStorage).
